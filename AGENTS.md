# Jayasri Makeovers Context
This is a mobile-first Next.js portfolio website for ISO Certified Makeup Artist Jayasri.
- **Tech**: Next.js (App Router), Tailwind v4 (tokens in `globals.css`).
- **Mobile First**: Everything is forced into `<MobileContainer>` since 100% of traffic is mobile.
- **i18n**: English/Kannada toggled via LanguageContext.
If you need a refresher on the architecture, read `.agent/skills/jayasri-context/SKILL.md`.
